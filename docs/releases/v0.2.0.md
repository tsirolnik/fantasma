# Fantasma v0.2.0 — interactive investigations and reviewed goals

This experimental release brings the current interactive workspace, persistent
sessions and goal review to the downloadable packages.

## Included

- Persistent investigation goals with completion criteria and a separate,
  evidence-based completion reviewer.
- Saved tool observations available to the reviewer after interrupted sessions
  and repeated resumes.
- `request_scope` for explicit user approval of additional authorized hosts.
- Provider-native reasoning retention, enabled by default and configurable with
  `[llm] retain_thinking`; optional reasoning can be disabled.
- Markdown conversation, activity indicators, tool/context inspection, steering,
  cancellation, session resume and Mac-friendly terminal controls.
- Browser-backed search without a search API key, configurable model providers,
  Python extensions and MCP tools.
- A reproducible local framework integration harness with vulnerable/fixed
  controls, offline checks and optional budgeted live-provider runs.

## Install or upgrade

Requires Python 3.13+ on Linux or macOS. For a checkout pinned to this release:

```sh
git clone --branch v0.2.0 https://github.com/tsirolnik/fantasma.git
cd fantasma
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
fantasma --version
```

Alternatively, download the release wheel and install it in an activated environment:

```sh
python -m pip install ./fantasma-0.2.0-py3-none-any.whl
```

This release is not published to PyPI. See the
[setup guide](https://github.com/tsirolnik/fantasma/blob/v0.2.0/docs/getting-started.md)
for model configuration, Chromium and Docker tools. Restart running processes
after upgrading. Resumed sessions wait for user input before continuing.

## Limits

This is an early release for authorized security research. Goal review checks
recorded evidence; it does not independently rerun exploits or prove findings.
Saved observations are bounded and may be truncated. Resume restores saved
context, not live processes. Budget estimates can overshoot by an in-flight call.
Tests and synthetic evaluations do not establish real-world detection quality.
Windows terminal interaction is not supported. MCP OAuth, prompts, standalone
resources and live catalog refresh are not implemented.

The original v0.1.0 tag and assets remain unchanged.
