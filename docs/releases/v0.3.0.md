# Fantasma v0.3.0: PyPI package

This experimental release makes Fantasma installable from PyPI with
`pip install fantasma`. It does not change investigation behavior.

## Changed

- All code now lives under the `fantasma` package (`fantasma.agents`,
  `fantasma.memory`, `fantasma.profiles`, …). Earlier wheels installed generic
  top-level modules such as `utils`, `config` and `models`, which could collide
  with other packages in the same environment.
- New `fantasma tools build` command builds the `bugbounty-tools:latest`
  container image from a Dockerfile bundled with the package, so you no longer
  need a checkout to build it. `fantasma tools dockerfile` prints the
  Dockerfile's path.
- `python -m fantasma` runs the CLI. In a checkout, `python main.py` still works.
- Report templates are bundled. A `templates/report.md` in the working
  directory still overrides the bundled one.
- New [comparison with ARTEX](../comparison.md) and an
  [offline local walkthrough](../local-evaluation.md).

## Upgrading extensions

Import from the new package paths, for example
`from fantasma.memory.mechanisms import Mechanism`. Profiles that use the old
dotted class paths, such as `memory.mechanisms:FirstFinderBonus`, keep working:
if the old path can't be imported, Fantasma looks for it under `fantasma.`.

## Install

Requires Python 3.13+ on Linux or macOS.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install fantasma==0.3.0
python -m playwright install chromium
fantasma tools build
```
